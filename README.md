# AI Skills Pack

Reusable AI skills for communication, development, analysis, research, and automation.

## Purpose

This repository contains reusable AI skills that can be used across ChatGPT Projects, Claude Projects, Kiro, VS Code/Copilot, Cursor, Windsurf, Roo Code, Cline, and other AI agent systems.

Each skill contains clear instructions, workflows, examples, and supporting references.

## Available Skills

### Communication
- `communication-skill`

Use for emails, tickets, documentation, executive summaries, technical explanations, public content, and general writing.

### Build
- `build`

Combined build skill covering creator, frontend design, UI/UX, testing, performance optimization, Vercel, React, and web design guidelines.

### Thinking
- `thinking`

Combined thinking skill covering problem solving, simplifying complex information, and clear concise writing.

### Research
- `research`

Research, browsing, summarizing, and extracting useful information.

### System
- `system`

Skill orchestration, superpower workflow, and platform behavior rules.

## Recommended Use

For most writing:

```text
Use Communication Skill.
```

For app building:

```text
Use Build Skill.
```

For problem solving or simplifying:

```text
Use Thinking Skill.
```

For online research or article summaries:

```text
Use Research Skill.
```

## Notes

The Communication Skill is the foundation for all written output.

When another skill produces writing, summaries, explanations, tickets, emails, or documentation, apply the Communication Skill rules to keep the output clear, specific, and natural.
