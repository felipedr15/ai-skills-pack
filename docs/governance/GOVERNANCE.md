# Governance

Humans own final decisions. Maintainers steward registries and shared guidance; contributors propose focused changes.

## Lifecycles
Skills use `draft`, `experimental`, `stable`, `deprecated`, or `archived`. Prompts and specifications move through draft, review, approval, use, revision, and retirement. Deprecation must name a migration when one exists; history is preserved.

## Approval and Review
Changes require scope review, metadata and registry consistency, documentation, validation, security review proportional to risk, and changelog updates. Versions follow semantic versioning where meaningful. Release readiness requires passing required checks, documented warnings, human approval, release notes, and rollback planning. Security concerns may block release.
