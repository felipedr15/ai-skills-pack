# Build Skill

Combined skill for building apps, interfaces, deployments, and production-ready web work.

This combines Creator, Frontend Design, UI/UX Pro Max, Testing, Performance Optimization, Vercel Agent, Vercel React, and Web Design Guidelines.

## Purpose

Turn ideas into working solutions quickly while keeping the output clean, usable, testable, and production-ready.

## When To Use

Use this skill for:

- Building an app or feature
- Designing a UI
- Reviewing frontend code
- Improving layout or UX
- Debugging UI issues
- Preparing React apps for deployment
- Deploying to Vercel
- Improving performance
- Testing app logic
- Creating MVPs

## Core Workflow

1. Understand the request
2. Define the user goal
3. Break the work into components
4. Choose the simplest stack
5. Design the layout and flow
6. Build the solution
7. Test for issues
8. Optimize only where useful
9. Prepare production/deployment notes

## Creator Mode

Goal:
Turn ideas into working solutions quickly.

Rules:

- No overengineering
- Deliver MVP first
- Use clean structure
- Keep it simple and functional

Output:

- Step-by-step plan
- Working code
- Clear setup steps

## Frontend Design Mode

Goal:
Create clean, modern interfaces.

Rules:

- Responsive on mobile and desktop
- Clean spacing
- Clear hierarchy
- Accessible
- Consistent UI patterns

Tech:

- React
- Tailwind or clean CSS

Output:

- UI layout
- Component structure
- Code

## UI/UX Pro Max Mode

Goal:
Design polished, modern, user-friendly interfaces that are visually clean and easy to use.

Focus:

- Layout
- Hierarchy
- Spacing
- Responsiveness
- Accessibility
- User flow
- Visual consistency
- Conversion and usability

Steps:

1. Understand the user goal
2. Define the primary actions
3. Organize the layout by priority
4. Improve hierarchy and spacing
5. Simplify navigation
6. Make it responsive
7. Improve usability and polish

Check for:

- Poor spacing
- Weak hierarchy
- Overloaded screens
- Too many competing actions
- Inconsistent UI patterns
- Weak mobile responsiveness
- Low contrast
- Confusing user flow

Output:

- UI/UX review
- Key problems
- Recommended improvements
- Layout guidance
- Component suggestions
- Optional production-ready UI prompt

Find and fix issues.

Focus:

- Edge cases

Output:

## Performance Optimization Mode

Goal:
Make apps, pages, and workflows faster, lighter, and more efficient.

Focus:

- Frontend performance
- React rendering efficiency
- Slow loading issues
- Re-renders
- Large bundles
- Expensive logic
- Unnecessary API calls

Steps:

1. Identify bottlenecks
2. Find unnecessary work
3. Reduce complexity
4. Improve load speed
5. Improve runtime responsiveness
6. Recommend measurable improvements

Rules:

- Focus on biggest wins first
- Prefer simple optimizations over advanced tricks
- Do not optimize prematurely
- Explain tradeoffs briefly
- Keep solutions maintainable

Check for:

- Unnecessary re-renders
- Large components
- Repeated calculations
- Missing lazy loading
- Poor state structure
- Heavy assets
- Blocking requests
- Unoptimized list rendering

Output:

- Main bottlenecks
- Priority fixes
- Optimized code or logic
- Expected impact

## Vercel Agent Mode

Goal:
Help build, prepare, debug, and deploy modern web apps to Vercel.

Focus:

- React apps
- Next.js apps
- Environment variables
- Build errors
- Deployment issues
- Vercel-friendly project structure

Steps:

1. Review project structure
2. Identify framework and build process
3. Check package scripts
4. Check environment variables
5. Identify deployment blockers
6. Recommend the simplest fix
7. Output production-ready guidance

Check for:

- Correct build command
- Correct output settings
- Missing or misnamed environment variables
- API routes and server/client separation
- Framework compatibility
- Static vs dynamic rendering opportunities

Output:

- Deployment assessment
- Issues found
- Fix steps
- Recommended config
- Production notes

## Vercel React Best Practices

Rules:

- Use components
- Keep state simple
- Optimize performance where useful
- Keep clean folder structure
- Use lazy loading when appropriate
- Separate API logic
- Use environment variables properly

Output:

- Clean React app
- Ready for Vercel deployment

## Web Design Guidelines Mode
