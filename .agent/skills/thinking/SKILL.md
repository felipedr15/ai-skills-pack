# Thinking Skill

Combined skill for problem solving, simplification, and clear concise writing.

This combines Problem Solving, Simplify, and Clear and Concise Writing.

## Purpose

Solve complex problems step-by-step and explain the result clearly.

## When To Use

Use this skill for:

- Breaking down complex tasks
- Simplifying messy information
- Rewriting unclear text
- Explaining technical concepts
- Creating executive summaries
- Turning rough notes into clear instructions

## Problem Solving Mode

Goal:
Solve complex problems step-by-step.

Steps:

1. Define the problem clearly
2. Break it into smaller tasks
3. Solve each part
4. Combine the solution

Rules:

- Keep it logical
- Avoid assumptions
- State unknowns clearly
- Separate facts from guesses

Output:

- Step-by-step solution

## Simplify Mode

Goal:
Take complex, messy, or technical information and make it clear, short, and easy to understand.

Use cases:

- Emails
- Documentation
- Code explanations
- Processes
- Technical concepts

Steps:

1. Understand the original content
2. Remove unnecessary complexity
3. Keep only what matters
4. Rewrite in plain language
5. Preserve meaning

Rules:

- Shorter is better
- No jargon unless necessary
- Use clear structure if helpful
- Keep tone professional and direct

Modes:

- Simple: plain explanation
- Executive: short summary for leadership
- Technical: simplified but still precise

Output:

- Simplified version
- Optional bullet summary

## Clear and Concise Writing Mode

Goal:
Rewrite content so it is clear, concise, direct, and easy to understand.

Use cases:

- Emails
- Ticket updates
- Documentation
- Executive summaries
- Technical explanations
- Instructions

Steps:

1. Understand the message
2. Remove filler and repetition
3. Use plain language
4. Keep key meaning intact
5. Improve flow and readability

Rules:

- Keep it short
- Use direct language
- Avoid jargon unless needed
- Preserve the original intent
- Make every sentence useful

Style:

- Professional
- Clear
- Direct
- Easy to scan

Output:

- Rewritten version
- Optional shorter version
- Optional subject line if useful

## Output Format

For problem solving:

1. Problem
2. Key facts
3. Steps
4. Recommendation
5. Next action

For simplification:

1. Simplified version
2. Optional bullet summary

For rewriting:

1. Revised version
2. Optional shorter version
3. Optional subject line
