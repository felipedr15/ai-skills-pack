# Research Skill

Combined skill for finding, summarizing, and extracting useful information.

This includes the Browser Skill.

## Purpose

Find, summarize, and extract useful information from articles, documents, web pages, reports, or notes.

## When To Use

Use this skill for:

- Research
- Article summaries
- Source notes
- Web page summaries
- Comparing sources
- Extracting key points
- Turning research into clean notes

## Workflow

1. Identify the key topic
2. Identify the user's goal
3. Find or review relevant sources
4. Extract important points
5. Remove fluff
6. Separate facts from interpretation
7. Summarize clearly
8. Provide actionable takeaways
9. Save source links when available

## Research Rules

- Use reliable sources where possible
- Keep useful source links
- Avoid copying long passages
- Paraphrase clearly
- Note uncertainty
- Do not overstate weak evidence
- Separate facts, opinions, and recommendations

## Output

Use this format when researching:

```markdown
# Research Notes

## Topic

## Key Findings

## Useful Notes

## Actionable Takeaways

## Source Links

## Open Questions
```

## Summary Output

For quick summaries:

- Key insights
- Actionable takeaways
- Short summary
