# AI-Skills

Reusable communication skill package for ChatGPT, Claude, Kiro, VS Code/Copilot, Cursor, Windsurf, Roo Code, and Cline.

## Files

- `SKILL.md`  
  Main skill file. Use this as the primary instruction file.

- `anti-ai-writing.md`  
  Supporting reference file. Helps identify common AI writing patterns.

## Recommended Use

Use `SKILL.md` as the main rule/instruction file.

Use `anti-ai-writing.md` as supporting knowledge or reference.

## Purpose

Communication Skill is a human-centered communication framework.

Goals:

- Improve clarity
- Improve specificity
- Reduce AI-sounding language
- Improve professional communication
- Improve technical communication

Works for:

- Email
- Chat
- Tickets
- Documentation
- Executive summaries
- Technical writing
- Public content

## Simple Prompt

Use this in any chat:

> Use Skill. Write clearly, naturally, and specifically. Remove AI-sounding filler, generic openings, buzzwords, and overly polished structure.

## Best Setup

Upload or reference both files, but prioritize the skill file.

The skill file tells the AI how to behave.

The anti-AI file explains what patterns to avoid.
