# Feature Specifications

Canonical feature specifications (requirements, design, tasks) live under [`specs/`](../../specs/README.md), not here. `.kiro/` is reserved for Kiro-specific configuration, workspace state, prompts, or temporary metadata, so that the specifications themselves stay usable by Kiro, ChatGPT, Claude, Codex, Copilot, and human contributors without depending on any one tool's directory conventions.

If a feature previously had content under `.kiro/specs/[feature-name]/`, that directory now holds only a lightweight pointer README to its canonical location under `specs/[feature-name]/`.
