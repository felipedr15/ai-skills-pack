# Feature Specifications

Organize substantial features as:

```text
.kiro/specs/[feature-name]/
├── requirements.md
├── design.md
└── tasks.md
```

Use lowercase hyphenated feature names, trace tasks to requirement IDs, record approval, and keep durable decisions in `decisions.md`. These files are reusable context; tool behavior depends on configuration.
