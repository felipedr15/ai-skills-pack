# Structure Steering

Five layers organize skills at `.agent/skills/`, core instructions/roles/prompts/standards, specifications under `specs/` and memory under `templates/`, starters under `templates/project-starters/`, and knowledge/platform notes under `knowledge/` and `references/`. Registries use actual paths; do not duplicate skills.

This file is repository guidance and does not claim automatic Kiro behavior.
