# Product Steering

AI OS serves developers, analysts, documentarians, and maintainers who need portable AI workflows. It solves fragmented instructions, lost decisions, weak traceability, inconsistent handoffs, and unsafe automation. Capabilities include skills, roles, prompts, specs, memory, starters, standards, validation, and references. Non-goals include being an OS, agent runtime, secret store, or automatic deployment authority.

This file is repository guidance and does not claim automatic Kiro behavior.
