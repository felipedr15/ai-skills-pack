# Copilot CLI Tool Mapping

Skills may reference Claude Code tool names. When using Copilot CLI, map them like this:

| Skill references | Copilot CLI equivalent |
|---|---|
| `Read` | `view` |
| `Write` | `create` |
| `Edit` | `edit` |
| `Bash` | `bash` |
| `Grep` | `grep` |
| `Glob` | `glob` |
| `Skill` | `skill` |
| `WebFetch` | `web_fetch` |
| `Task` | `task` |
| `TodoWrite` | `sql` with built-in todos table |

## Notes

Use Copilot CLI native tools when available.
