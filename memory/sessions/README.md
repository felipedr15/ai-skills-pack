# Session Memory

Purpose: hold temporary, in-progress context for active work.

What belongs here:

- current goal and findings
- files examined and work in progress
- blockers and next action

What must not be stored:

- secrets or personal data
- durable decisions that should be in `memory/decisions/`
- reusable lessons that should be in `memory/lessons/`

Naming convention: `session-<topic>-NNN.md`.

Retention: temporary. Promote or archive when work completes.
