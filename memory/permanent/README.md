# Permanent Memory

Purpose: store long-lived standards that should survive individual projects and sessions.

What belongs here:

- conventions
- preferences
- principles

What must not be stored:

- secrets or personal data
- temporary session notes
- generated indexes

Naming convention: `<type>-<topic>-NNN.md` with stable IDs in front matter.

Retention: permanent unless superseded or explicitly archived.
