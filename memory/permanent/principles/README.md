# Principles

Purpose: store long-term principles that guide architecture and delivery choices.

What belongs here:

- design principles
- governance principles
- risk-management principles

What must not be stored:

- decision-specific implementation details better suited for decision records
- temporary notes

Naming convention: `principle-<topic>-NNN.md`.

Retention: permanent unless intentionally replaced.
