# Lessons Memory

Purpose: keep reusable lessons learned from troubleshooting and delivery.

What belongs here:

- situation and observation
- root cause and resolution
- reusable lesson and preventive action

What must not be stored:

- sensitive customer/employee records
- secrets or production credentials
- unresolved raw logs with private data

Naming convention: `lesson-<topic>-NNN.md`.

Retention: permanent for broadly reusable lessons, project for local lessons.
