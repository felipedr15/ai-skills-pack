# Decision Memory

Purpose: capture architecture and process decisions in ADR-style records.

What belongs here:

- context
- decision
- reason
- alternatives and consequences

What must not be stored:

- secrets
- unverified notes without a clear decision outcome

Naming convention: `decision-<topic>-NNN.md`.

Retention: keep until superseded, then mark superseded or archive.
