# Memory Archive

Purpose: retain archived memory records for traceability without deletion.

What belongs here:

- records whose status is `archived`
- superseded historical records moved out of active folders

What must not be stored:

- generated files
- orphaned records missing metadata

Naming convention: preserve the original record filename and ID.

Retention: long-term archive unless governance requires removal.
